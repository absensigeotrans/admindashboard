Mengapa GeoTrans?

Solusi mengatasi tantangan pencatatan kehadiran konvensional di Pertamina Trans Kontinental.

Masalah Absensi Konvensional

  • Ketidakakuratan lokasi pada absensi manual atau web-form biasa.
  • Tingginya potensi kecurangan (titip absen, fake GPS).
  • Kesulitan mengawasi karyawan lapangan (Driver, Juru Parkir, OB).
  • Perhitungan keterlambatan dan jam lembur yang memakan waktu (manual).

Solusi Geofencing

Membatasi absensi hanya pada area koordinat kantor yang sah. Dilengkapi deteksi kecurangan real-time yang langsung mengunci akses tombol check-in jika terdeteksi manipulasi GPS.

Efisiensi Operasional

Otomatisasi pengolahan data kehadiran, jam kerja, status telat, cuti/izin, dan perhitungan lembur langsung tersaji di dasbor admin HRD.

Ekosistem 3-Platform Terintegrasi

Sinergi infrastruktur cloud, antarmuka mobile karyawan, dan panel kontrol manajemen.

📱 Mobile App

Flutter + Dart

Aplikasi mobile untuk Driver, Juru Parkir, dan OB. Mendukung tracking latar belakang (background tracking), GPS presisi tinggi, camera selfie, dan database SQLite lokal saat offline.

🌐 Web Admin Panel

Next.js 16 + React 19

Dasbor real-time untuk HRD/Admin. Monitoring peta live, approval cuti, CRUD master data karyawan/kantor/shift, log anomali, report bulanan, serta fitur export CSV & PDF.

🗄️ Cloud Backend

Supabase / PostgreSQL

Mesin validasi utama di server. RLS (Row Level Security) ketat, database triggers untuk perhitungan jarak & lembur secara instan, storage untuk foto selfie, dan cron jobs retensi file.

Protokol Keamanan Anti-Fraud

Sistem proteksi multi-layer untuk menjamin validitas setiap data absensi yang masuk.

Mock GPS Block

Deteksi otomatis atas aplikasi manipulasi lokasi. Akun langsung terkunci dari check-in jika emulator/mocking aktif.

Device ID Binding

Membatasi 1 akun hanya dapat login di 1 smartphone. Mencegah praktik titip absen antar karyawan.

Server-side Verification

Perhitungan jarak haversine dilakukan ulang di sisi database PostgreSQL untuk mencegah bypass API client.

Selfie Lock

Pengambilan foto selfie kamera depan secara real-time yang memvalidasi kehadiran fisik karyawan secara sah.

Proteksi di Level Database

PostgreSQL Row Level Security (RLS) memastikan karyawan hanya bisa membaca & menulis baris kehadiran miliknya sendiri.

-- RLS Policy: User hanya bisa select data miliknya
CREATE POLICY user_select_own ON attendance
  FOR SELECT
  USING (auth.uid() = user_id);

Mekanisme Selfie Attendance

Proses verifikasi wajah otomatis dengan optimasi ukuran file untuk hemat kapasitas penyimpanan cloud.

1. Auto-Capture

Kamera depan aktif otomatis saat tombol absen ditekan. Countdown 2 detik langsung mengambil gambar.

2. Image Compression

Resolusi dikompresi ke 480x360 & quality 20%. Mengubah file foto berukuran besar menjadi hanya ~15-20 KB.

3. Secure Upload

Foto diunggah ke Supabase Storage bucket 'selfie_absensi' dengan hak akses terenkripsi.

4. Auto-Retention

Cron job menghapus foto secara permanen setelah 30 hari demi efisiensi storage cloud free-tier.

Sistem Shift & Lembur Otomatis

Sistem otomatisasi penentuan status hadir dan kalkulasi kompensasi lembur karyawan.

Shift Pagi vs Siang

Shift Pagi mulai 06:00 (telat > 07:00). Shift Siang mulai 10:00 (telat > 11:00). Status dihitung dinamis sesuai shift pilihan.

Aturan Lembur (Overtime)

Dihitung saat check-out. Kelebihan waktu di atas jam selesai shift minimal 15 menit akan dikonversi otomatis menjadi menit lembur.

Exception Dates (Pengecualian)

Admin dapat menentukan tanggal tertentu sebagai "Exception Date" (Hari Libur Bersama atau Hari Off Per-Karyawan).

  • Tanggal exception diperlakukan seperti weekend.
  • Tidak ada pengecekan keterlambatan (otomatis berstatus present).
  • Mengabaikan kalkulasi jam lembur pada tanggal tersebut.
  • Mempermudah pengelolaan hari libur dadakan tanpa mengubah master shift.
